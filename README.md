# Dormitory Management System

## Description
A web-based dormitory management system built with ASP.NET Core MVC, supporting room, student, contract, and service management.

## Technologies
- ASP.NET Core MVC
- SQL Server
- Entity Framework Core
- SignalR

## Features
- Room and student management
- Authentication and role-based authorization
- Real-time communication (SignalR)
- Image upload and file handling
